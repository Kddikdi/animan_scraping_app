# 反応集動画を作る

作品名と話数（「最新」も可）を受け取り、下の手順を順に行う。作業場所は `scraping_project/`、Pythonは `C:\Python313\python.exe`（`python` で起動するもの。`myenv` はPillowがなく使えない）。

## 設定

- **停止点: ON**
  - ON: 手順2（台本の精度上げ）のあとで止め、台本と判断の一覧を見せて「OK」を待つ
  - OFF: 止めずに手順3へ進む
  - ユーザーに「停止点をOFFにして」「ONにして」と言われたら、この行を書き換える
- 読み上げ音声: 冒頭・締めは `四国めたん`、レスは `ずんだもん`・`春日部つむぎ`・`青山龍星`・`冥鳴ひまり`
- 背景動画: `背景動画/` からランダム

## 守ること

- あにまん掲示板の規約: 使えるのは過去ログに格納されたスレだけ。現行スレしかなければ作らずに報告する。説明文の先頭の元スレURLと、動画冒頭の掲示板名は自動で入る
- 動画に作り手の言葉（話題の案内・解説・感想のセリフ）を足さない。読み上げるのはスレのレスだけ。冒頭と締めの定型あいさつはそのまま
- サイトへのアクセスは既存の処理の間隔（2〜3秒）を守り、403・429で止まったら回避せずに報告する

## 判断できないとき

- **対話のとき**（ユーザーがこの会話で返事できる）: その場で質問する。選択肢があれば並べて聞く
- **無人実行のとき**（頼む文に「無人実行」とある。タスクスケジューラからの `claude -p` はこれ）: 質問しない。判断に迷ったものは `台本チェック.txt` の「■ 要確認」欄に、迷った理由と仮に選んだ内容を書いて先へ進む。停止点がONなら、停止点でその一覧を見せる
- 迷ったときの仮の選び方: 読みはVOICEVOXの読みのまま（辞書に足さない）、行は残す、話題は動かさない

## 手順

### 1. 画像取得

作品が `感想サイト/data.json` に登録されていることを確認する。未登録なら、サイトの調査が必要だと伝えて止める（調査は手作業。README の「感想サイトの画像を集める」参照）。

```
python -W ignore -c "from app.contorollers import find_review_sites as f; [print(m) for m in f.collect_chapter_images('作品名', f.parse_chapters('話数または最新'))]"
```

- 結果の「◯話」から、使う話数を確定する（「最新」のときは結果に出た話数）
- 「差し替えられる候補がありません」が出たら、報告に含める（サイトの再調査が必要）
- 画像を集めると、吹き出しの文字の読み取りとキャラの別名の自動登録も行われる。1話あたり数分かかる

### 2. 台本

#### 2-1. 感想スレを探す

過去ログの漫画カテゴリ（11: ジャンプ、18: マガジン、1: その他漫画、16: ワンピース、15: 呪術廻戦）から、タイトルに作品名と「◯話」と「感想」を含むスレを探す。

```
python -W ignore -c "
import re, time, requests
from bs4 import BeautifulSoup
work, chapter = '作品名', 話数
for category in (18, 11, 1, 16):
    for page in range(1, 6):
        url = f'https://bbs.animanch.com/kakolog{category}/' + (f'page:{page}' if page > 1 else '')
        r = requests.get(url, timeout=30)
        if r.status_code != 200: print('stop', url, r.status_code); break
        for a in BeautifulSoup(r.text, 'html.parser').find(id='mainThread').find_all('a', href=True):
            t = a.get_text(' ', strip=True)
            if work in t and re.search(rf'(?<!\d){chapter}\s*話', t) and '感想' in t: print(t, a['href'])
        time.sleep(3)
"
```

- 同じ話の感想スレが複数（「感想スレ2」など）あれば全部使う
- 見つからなければ、まだ現行スレの可能性が高い。作らずに報告する

#### 2-2. 台本を作る

権利表記とハッシュタグは、同じ作品の前回の台本（`台本ファイル/【作品名◯話】に対する読者の反応集.meta.json`）から引き継ぐ。前回がなければユーザーに聞く。

```
python -W ignore -c "from app.contorollers import create_reaction_script as c; print(c.main(['スレURL', ...], [], '作品名◯話', '権利表記', 'ハッシュタグ', '四国めたん', ['ずんだもん','春日部つむぎ','青山龍星','冥鳴ひまり']))"
```

URLの取得が拒否されたら、ブラウザで保存したHTMLを使う方法（README の「話数感想スレの反応集動画を作る」）をユーザーに案内して止める。

#### 2-3. 台本の精度上げ（自分で判断する）

台本CSV（列: 音声, セリフ, コマ画像, 話題）を読み、1行ずつ判断する。1・2行目と最終行の定型あいさつは触らない。

**外す行**
- その話の内容と関係のないレス（他作品の話、スレ運営の話、雑談）
- 前後がないと意味が通らないレス（返信先が台本にない「それな」「これ」など）
- 人やキャラを強く貶めるだけのレス、差別的な表現、性的な表現（YouTubeに出せないもの）
- 創作イラスト・自作の話、宣伝
- 同じ内容の繰り返し（似たレスが続くときは、分かりやすい方を残す）

**直してよいこと（意味は変えない）**
- 読み上げにくい表記: 誤字、読めない記号、長すぎる「!!!」「...」の連続
- 1つのレスが長すぎるとき（字幕2画面を超える目安）、意味が切れない位置で文を省く

**直さないこと**
- 言い回しや口調、ネットスラング、感想の中身。足すことはしない

**並べ方**
- 話題（4列目）の振り分けが明らかにずれている行は、合う話題に移す。返信のやり取りは続けたまま動かす
- 全体の文字数の目安は3400字前後（読み上げ速度1.2で約8〜9分）。超える場合は、話題の中で印象の弱いレスから外す

判断が終わったら:
- 台本CSVを書き換える（文字コードは `utf-8-sig`、4列のまま。コマ画像列は空のままでよい）
- `台本ファイル/<台本名>.台本チェック.txt` に、外した行（理由つき）、直した行（前→後）、話題を移した行を書き出す

#### 2-4. 読みの確認（毎回必ず行う。自分で判断する）

読みはこの手順で毎回改善していく。どの作品でも省略しない。VOICEVOXを起動してから（手順3-2のコマンド）、各行の読みを一覧にする。

```
python -W ignore check_readings.py "台本名.csv"
```

先頭の「読みが未登録の名前」（キャラの別名辞書にあって読みが未登録の名前）は全部確かめ、正しい読みを `readings` に足す。VOICEVOXの読みが合っていても足す（次回から出なくなる）。

続けて、各行のカタカナの読みを見て読み間違いを探す。特にキャラ名・技名・チーム名・略語・英字・「〜草」の読み。読みに自信がない名前は「判断できないとき」に従う（対話なら質問、無人実行なら「要確認」）。見つけたら:
- 作品の語は `感想サイト/data.json` の作品の `readings` に `{"表記": "読み（カタカナ）"}` で足す
- 作品に関係ない語は `app/contorollers/reading_dict.py` の `COMMON_READINGS` に足す
- 足したら `check_readings.py` をもう一度実行して、直ったことと、普通の言葉（「潔く」など）が崩れていないことを確かめる
- 直した語を `台本チェック.txt` の最後に「読みを足した語」として書き足す

台本の表記は読みのために書き換えない（字幕に出るため）。辞書で直せないもの（記号・数字の並び）は `reading_dict.speech_text` に書き換えの規則を足す。

### ⏸ 停止点（設定がONのとき）

台本の行数・話題ごとの行数・外した行数・直した行数・読みを足した語・要確認の件数を短く報告し、`台本チェック.txt` を送る。要確認があれば、その内容を一つずつ聞く。ユーザーの「OK」を待つ。修正の指示があれば台本に反映してから進む。

### 3. 動画作成

1. コマの割り当て（2セリフごとに1枚、コメントに合う画像を選ぶ）

   ```
   python -W ignore assign_panels.py "台本名.csv" 作品名 話数
   ```

2. VOICEVOXを起動する（PowerShell）。`http://127.0.0.1:50021/version` が応答するまで待つ

   ```
   Start-Process -FilePath "$env:LOCALAPPDATA\Programs\VOICEVOX\VOICEVOX.exe"
   ```

3. 動画を書き出す（10分前後かかるので、バックグラウンドで実行する）

   ```
   python -W ignore -c "from app.contorollers import create_animan_video as v; print(v.main('台本名.csv', voicevox_url='http://127.0.0.1:50021', speed=1.2, background_video=v.resolve_background_video('random')))"
   ```

4. 出来上がりを確認する
   - 何か所か画面を切り出して、コマと字幕が出ているかを見る
   - スマホ確認用の軽量版を作って送る（送信上限30MBのため）

     ```
     ffmpeg -v error -y -i "出力動画/台本名.mp4" -vf scale=854:-2 -c:v libx264 -preset veryfast -b:v 380k -maxrate 450k -bufsize 900k -c:a aac -b:a 64k "<スクラッチパッド>/台本名_スマホ確認用.mp4"
     ```

   - 出力: `出力動画/` に動画・字幕（srt）・サムネイル・説明文（`_説明文.txt`）
