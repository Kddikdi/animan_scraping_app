# 感想サイト画像収集 要件定義

更新日: 2026-11-01 / 状態: 確定、実装済み（`/find_review_sites`）

## 1. 目的

主要な漫画について、感想を書いているサイトのURLを保存しておく。依頼があったときに、保存したサイトから指定の話の画像をフォルダへ入れ、どのような画像が使われているかを参考にする。

## 2. 要件

| ID | 要件 |
|---|---|
| R1 | 主要作品と、作品ごとのサイト2つを `感想サイト/data.json` に保存する。サイトの調査は作品ごとに1回だけ行う |
| R2 | サイトは「<作品> 最新話」のGoogle画像タブによく出るものから、公式・SNS・ニュース・通販・まとめ・海賊版を目視で除いて選ぶ |
| R3 | 話数を指定すると（`129`、`129-131`、`最新`、一度に10話まで）、保存したサイトから該当の記事を探す |
| R4 | 記事はリンク文字に作品名（別名を含む）と話数の両方を含むものとする。サイト名に作品名が入った専門サイトでは話数だけでよい。サイト内検索（`/?s=`、`/search?q=`）、カテゴリ一覧（`/archive/category/<作品>`）の順に探す |
| R5 | 記事本文の画像を `参考画像/<作品>/<サイト>/<N>話 画像/` に保存する（1話1サイト最大3記事） |
| R5a | 記事に出典が書かれた画像（キャプション、または画像の直後の「出典」「引用」「©」「〜より」の行）は、巻数・話数ごとに `出典 102巻/` のようなサブフォルダに分ける。出典のない画像は話のフォルダ直下に置く。画像ごとのURLと出典を `取得元.txt` に残す |
| R6 | 保存済みの話は取得し直さない。サイトごとの結果（枚数、記事なし、拒否）を表示する |
| R7 | 記事が見つからないときは、各サイトに掲載されている最新の話数から理由を判定して表示する（下表） |
| R8 | 更新をやめたサイトは「過去のサイト」（`past_sites`、最終話数と日付つき）に移し、候補（`candidates`）のうち更新が続いているサイトに差し替える |
| R9 | 過去のサイトも、最後に更新していた話までは画像の取得に使う |
| R10 | 依頼のたびに保存サイトと候補の掲載最新話を確認し、公開済みの最新話を決めてから差し替えを行う（保存サイト2つが同時に止まっていても気づけるように） |
| R12 | 記事はあるのに画像がない回が2回続いたサイトは、文章だけのサイトとして外し（`excluded_sites`、理由と日付つき）、候補から差し替えて同じ話を集める。画像があれば回数は0に戻す |
| R13 | 話数は「55話」「第55話」「#55」を読む。アニメの話数の記事は数えない。専門サイトの判定はトップページのタイトルで行う（検索結果のページは検索語をタイトルに含むため） |
| R14 | 会話形式の吹き出しのアイコン、筆者紹介、商品紹介の枠の画像は保存しない。www.付きでしか接続できないサイトにも対応する |
| R15 | 白黒のコマに色付きの文字等を重ねた加工画像は保存しない。鮮やかな画素（RGBの差80以上）が0.1%を超え、色の付いた画素（差40以上）が10%以下で、鮮やかな色が1〜2色（色相12区分の上位2つで95%以上）なら加工とみなす。電子版等のカラーページは残す |
| R11 | 「◯話以降」「予想」「早バレ」「確定速報」の記事は話数として扱わない。発売前に流出した雑誌の写真を載せるサイトは使わない |

### 記事が見つからないときの判定

公開済みの最新話は、保存サイトと候補のどこかに記事がある最新の話とする。

| パターン | 条件 | 対応 |
|---|---|---|
| 未公開（休載を含む） | どのサイトにも記事がなく、指定の話が公開済みの最新話より新しい | 表示のみ |
| 更新停止 | サイトの最新話が公開済みの最新話から3話以上遅れている | 過去のサイトに移し、遅れが3話未満の候補に差し替える。候補がなければ再調査を促す |
| 更新待ち | 遅れが1〜2話 | 表示のみ |
| この話だけない | サイトに指定の話より新しい記事がある（タイトル形式の違い、抜け回） | 表示のみ |
| 判定不能 | サイトの一覧から話数を読めない | 表示のみ |
| 拒否・通信エラー | 403・429、接続失敗 | 止めて表示 |

## 3. 範囲外

- トレンド作品の自動集計、ブックマークによるURL取り込み（2026-11-01に不要と判断して削除）
- Google検索のアプリからの実行。作品を増やすときは調査を依頼し、`data.json` に追記する
- 集めた画像の動画への利用

## 4. 制約

- 画像の取得は `fetch_images.py` を使い、robots.txtで禁止されたページは取得せず、403・429で止まる
- 参考画像は `コマ画像/` と分ける。「コマの収集元はスレ内のみ」の既存方針は変えない

## 5. 既知の制限

- カラー画像に重ねた文字、白黒のまま加工した画像（コマの貼り合わせ、白黒の文字入れ）、漫画と無関係な写真は判別できない。公式のカラー版とファンの着色も区別できない

- タイトルに作品名や話数がない記事は見つからない
- 検索機能もカテゴリ一覧もないサイトでは記事が見つからない
- 調査時に記事を特定できなかったサイトも、Googleでの出現数を基準に保存している
- 更新停止の判定は話数の遅れだけで行う。全サイトが同時に止まった場合は未公開と区別できない
