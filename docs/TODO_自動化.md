## 1. YouTubeへの投稿（スキルの手順4）

- [ ] Google Cloud でプロジェクトを作り、YouTube Data API v3 を有効にする（**ユーザー本人のGoogleアカウントでの操作**）
- [ ] OAuth クライアント（デスクトップアプリ）を作り、`client_secret.json` をPCに置く（リポジトリには入れない）
- [ ] 初回だけブラウザでログイン・許可し、トークンを保存する。以後はトークンで投稿する
- [ ] `scraping_project/upload_youtube.py` を作る: 動画・サムネイル・説明文（`_説明文.txt`）・タイトル・タグを指定して投稿する
- [ ] 公開範囲の既定は **非公開**。人が確認してから公開する（権利表記・掲載内容の確認のため）
- [ ] スキルの手順4に組み込む

## 2. タスクスケジューラでの定時実行

- [ ] 非対話モードで起動する: `claude -p "ブルーロックの最新話の反応集を作って"`

- [ ] 停止点がONの間は、定時実行は手順2で止まる。止まったことを知らせる方法（通知など）を決める
- [ ] Windows のタスクスケジューラに登録する（作品・曜日・時刻）

## 3. 停止点

- [ ] 何本か作って台本の精度上げが安定したら、スキルの「停止点」をOFFにする（「停止点をOFFにして」と頼む）
