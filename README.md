あにまんというサイトの過去ログ（https://bbs.animanch.com/kakolog/） の情報をまとめるためのもの  
1.URL抽出ページ  
各スレッドのタイトル、コメント数、URLを抽出し、エクセル出力するもの  
2.台本作成ページ  
スレッドURLを入力するとYMM4に自動読み込みが出来るcsvファイルを作成する。  
3.動画作成ページ  
台本ファイル（csv）からVOICEVOXで音声を合成し、反応集動画（mp4）を作成する。  
出力先：`scraping_project/出力動画/`（動画・字幕srt・サムネイル画像）  

### 動画作成の準備
- [VOICEVOX](https://voicevox.hiroshiba.jp/) を起動しておく（エンジンが http://127.0.0.1:50021 で待ち受ける）
- [ffmpeg](https://ffmpeg.org/) をインストールしてPATHを通す（または環境変数 `FFMPEG_PATH` にffmpeg.exeのパスを設定）
- `pip install -r requirements.txt`

### 使い方
1. 台本作成ページでスレッドURLから台本csvを作成（必要ならExcel等で不要なレスを削除・編集）
2. 動画作成ページで台本を選び、背景画像・BGMを指定して作成  
   コマンドラインからも作成可能：`python make_video.py 台本名.csv --background 背景.png --bgm bgm.mp3`  
   `--silent` を付けるとVOICEVOXなしでレイアウト確認用の動画を作成する

### 話数感想スレの反応集動画を作る
1. 反応集台本作成ページで感想スレのURLを指定する。取得が拒否される場合は、ブラウザでスレを開いて「ウェブページ、完全」で `scraping_project/保存スレ/` に保存し、一覧から選ぶ
2. レスの選別・話題ごとの並べ替え・スレの画像のコマ収集（`scraping_project/コマ画像/`）が自動で行われ、台本csvができる
3. コマは台本の3列目（コマ画像）を書き換えれば後から追加・差し替えできる。空欄の行は話題名を表示する
4. 動画作成ページで台本を選ぶと、中央にコマ・下部に字幕のレイアウトで動画と説明文（`_説明文.txt`）が出力される

### 背景にフリー動画を使う（反応集の台本のみ）
- フリー動画を `scraping_project/背景動画/` に置き、動画作成ページで選ぶ（既定はランダム）。短い動画はループし、縦横比が違う動画は切り抜いて画面を埋める
- Pexelsから自動取得する場合は無料のAPIキーを取得して環境変数 `PEXELS_API_KEY` に設定し、動画作成ページに検索キーワードを入れる
- 素材のライセンスは配布元の条件を確認する。背景動画ありの作成は書き出しに時間がかかる

### サムネイルを作る
- サムネ作成ページで台本を選ぶと、台本から吹き出し4つ・下部の文字・コマが初期入力される。修正して作成すると `出力動画/<タイトル>_thumbnail.jpg` に出力する
- 修正内容は台本の `.meta.json` に保存され、動画を作り直しても上書きされない。動画作成時は保存した設定で自動出力する（未設定なら初期値）
- 見た目の種類は `app/contorollers/thumbnail_template.py` の `TEMPLATES` で追加できる

あにまん掲示板のコンテンツ使用規約（ https://bbs.animanch.com/board/905570/ ）に従うこと
- 使用できるのは過去ログのスレのみ（現行スレは台本作成を中止する。削除されたスレは使用禁止）
- YouTube説明文の先頭に元スレのURLを全て記載する（`_説明文.txt` の先頭に自動で入る。投稿時に動かさない）
- 動画内の先頭に掲示板名『あにまん掲示板』を記載する（1画面目に自動で入る）
- 創作イラストの転載は禁止。本文から明らかなものは収集しないが完全には判定できないため、公開前に `コマ画像/` を目視で確認する
- ステルスマーケティングでの使用、掲示板の規約で禁止されているスレ・レスの使用は禁止

### スマホからこのPCで実行する
1. PCで `scraping_project/start_for_smartphone.bat` を実行する（PowerShell等なら `APP_HOST=0.0.0.0` を環境変数に設定して `python run.py`）
2. 画面に表示された `http://192.168.x.x:5000` をスマホのブラウザで開く（PCとスマホは同じWi-Fi）
3. 開けない場合はWindowsファイアウォールでPython(ポート5000)の受信を許可する

- 作成処理は**PC上で**実行されます。VOICEVOX・ffmpegもPC側で起動・用意しておいてください（VOICEVOXエンジンURLは `http://127.0.0.1:50021` のままでOK）
- 外出先から使う場合は [Tailscale](https://tailscale.com/) をPCとスマホに入れ、表示されるTailscaleのIPで `http://<TailscaleのIP>:5000` を開く（ルーターのポート開放はしないこと。認証がないため）
- 外部公開モードではFlaskのデバッグモードは自動的にOFFになる。ポート変更は `APP_PORT` で指定
